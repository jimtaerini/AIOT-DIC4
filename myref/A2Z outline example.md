# 2020 A-Z SOP（論文寫作大綱）

> 原始檔：[A2Z outline example.pdf](A2Z%20outline%20example.pdf)。本檔為其文字版，供撰寫論文與 OpenSpec 規格引用。

## Abstract

- **A. Attention Getter**：Motivation 動機及引題（科技進步…，research interest）
- **B. But**：However 挑戰
- **C. Cure**：解藥（we propose a novel scheme to address the challenges）
- **D. Development**：我們的方法設計 based on …
- **E. Experiments**：To evaluate our proposed scheme, we conduct experiments on …
- **F. Findings**：results show that …

## I. Introduction

- **G. General**：現況（with the explosive growth of … xxx has great improvement）
- **H. However**：挑戰，same as B… but longer
- **I. In literature**：文獻中有關此問題的解，大分類 from old to new, simple to complex
- **J. Judgement**：評論各類方法優缺點，SWOT
- **K. Keypoint**：設計精神與 novelty，再次強調 major goals，contribution summary
- **L. List the organization**：文章結構交代

## II. Related Work

- **M. Methods**：文獻中有關此問題的解，分類 from old to new, simple to complex
- **N. New proposed**：new trend, new novelty of the proposed scheme
- **O. Organize**：based on Judgement 評論各類方法優缺點，SWOT 列表（4x5 table）歸納

## III. Proposed Scheme（From PA to PM）

| 代號 | 內容 |
|---|---|
| PA | Aim = Statement 目標 |
| PB | Based on / background / Be focus on / Benefit |
| PC | Cure / Cause / 解法及有用的原因 |
| PD | Design 架構（paper 的設計是結合…怎樣典範轉移成為這篇重點） |
| PE | Paper element（有哪些 element） |
| PF | Formulation / Foundation 功能 |
| PG | Graph（架構圖說明） |
| PH | How（How they achieve the design goal） |
| PI | Implementation / Interaction among elements / flow chart or pseudo code |
| PJ | Jump to an example |
| PK | Key points contribution |
| PL | Later how to do simulation |
| PM | Math proof |

## IV. Simulation

- **Q. Quality and Quantity**：實驗量與性質指標，performance metrics
- **R. Related method to compare**：比較哪些演算法
- **S. Simulation Setup**
- **T. Tuning**：tuning what parameters in simulations
- **U. Useful results**
- **V. Verify**：verify the effectiveness of our proposed scheme

## V. Conclusion

- **W. What proposed**：回顧研究意義、動機、研究挑戰
- **X. eXcel**：專精哪種情境，演算法優點，這篇文章解決的問題、提出的 solution 及方法
- **Y. Yields**：產出，results show …，實驗數據與模擬與結果簡述
- **Z. Zen**：結論與 future work，最後強調問題獲得怎樣的解決與結論、觀察與研究貢獻
