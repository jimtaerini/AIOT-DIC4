# Design：000_abstract

## Context

摘要已依 A–F 寫成單一段落（187 字），每段前有 `% [A2Z:A]`…`% [A2Z:F]` 註解；F 段為 `[TBD]`。數字依 `my_ref/README.md`。

## Goals / Non-Goals

**Goals:** 一句到兩句對應一個字母，讓 A→F 可逐句追溯；不超過 250 字。

**Non-Goals:** 不在摘要放引用編號或未完成的實驗數字。

## Decisions

1. **A–F 一對一句群**：每個字母以註解標記，檢查腳本可確認順序（A2Z A–F）。
2. **E 只寫可驗證的資料規模**：707,108 起事件、5,769 個組織來自實測（`my_ref/README.md`），不寫預期分數。
3. **F 在實驗前保留 `[TBD]`**：摘要投稿前若 E1 未完成，F 改寫為不含數字的貢獻敘述，而不是填入預期值。

## Risks / Trade-offs

- [摘要投稿時 E1 尚未完成] → F 改為描述可量化的取捨與評估設計，全文投稿前再補數字。
